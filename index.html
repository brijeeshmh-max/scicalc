SHIFT (yellow) and ALPHA (red) pick the small labels above each key. To save a value: SHIFT, RCL, then a variable key (A–F, X, Y, M). Keyboard works too: digits, + − * / ( ), Enter, Backspace, Esc, arrows. Equation solver: press ALPHA then MODE to cycle EQN2 (quadratic), EQN3 (cubic) and off. Type each coefficient, press = after each, then = again for the next root.
